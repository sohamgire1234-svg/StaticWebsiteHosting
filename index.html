Welcome to my cloud computing project. This website explains how a static website can be published online using GitHub Pages.

Explore Project

About the Project

Understanding the basics of hosting a website on the internet.

01. What is Cloud Hosting?

Cloud hosting allows website files to be stored on internet-connected infrastructure and accessed by users through a web browser.

02. Technologies Used

HTML is used for the structure, CSS for the design, and JavaScript for simple interactive features.

03. Why GitHub Pages?

GitHub Pages provides a convenient way to publish static websites directly from a GitHub repository.

How Does It Work?

The basic process used to publish this website.

  1. Create the website using HTML, CSS and JavaScript.
  2. Upload the website files to a GitHub repository.
  3. Enable GitHub Pages in the repository settings.
  4. Wait for deployment to finish.
  5. Open and share the published website link.
