Web Technologies

GitHub Pages

GitHub Pages publishes supported static website files from a GitHub repository.

📱

Responsive Design

🔒

HTTPS Support

HTTPS protects information sent between a visitor's browser and the website.

⚡

Static websites can load efficiently because they do not require server-side processing.

How Hosting Works

Follow these four steps to publish a static website.

1

Create Website Files

Write the website using HTML, CSS and JavaScript.

2

Upload to GitHub

Create a repository and upload your index.html file.

3

Enable GitHub Pages

Open Settings → Pages, select the main branch and root folder, and save.

4

Visit Your Website

After deployment, open the live link and share it with others.
